# MangaLens TH — Android prototype 0.1

โปรเจกต์ต้นแบบสำหรับ Android: ขออนุญาตจับหน้าจอ, สร้าง foreground service,
ใช้ ML Kit OCR และแสดงกรอบข้อความแบบ overlay

## สถานะสำคัญ
- รุ่นนี้เป็นโครงสร้างทดลอง OCR + overlay เท่านั้น
- ยัง **ไม่ได้แปลข้อความเป็นภาษาไทยจริง**; ข้อความบน overlay ยังเป็นข้อความต้นฉบับ
- โหมดตรวจจับอัตโนมัติยังเป็นตัวเลือกเริ่มต้นที่ใช้ OCR เกาหลี ไม่ใช่ language detection ที่สมบูรณ์
- ต้องทดสอบกับ Android รุ่นและเว็บไซต์จริงก่อนใช้งานประจำ
- Android อาจไม่อนุญาตจับภาพหน้าจอบางแอป/บางหน้าที่ใช้ FLAG_SECURE
- ภาพหน้าจอถูกประมวลผลในเครื่องในต้นแบบนี้ ไม่ได้ส่งไปเซิร์ฟเวอร์

## สร้าง APK โดยใช้มือถืออย่างเดียว
วิธีที่สะดวกคือใช้ GitHub Actions:
1. สร้างบัญชี GitHub หากยังไม่มี
2. สร้าง repository ใหม่ชื่อ `MangaLensTH`
3. อัปโหลดไฟล์ทั้งหมดใน ZIP นี้เข้า repository โดยคงโครงสร้างโฟลเดอร์
4. เปิดแท็บ Actions แล้วเลือก `Build MangaLens TH APK`
5. กด `Run workflow`
6. เมื่อ build สำเร็จ เปิดรายการ workflow run แล้วดาวน์โหลด artifact `MangaLensTH-debug-apk`
7. แตก ZIP artifact แล้วติดตั้ง `app-debug.apk` บน Android

## การอนุญาตในมือถือ
1. เปิดแอป
2. กดอนุญาตให้แสดงคำแปลทับแอปอื่น
3. กลับมาแอปแล้วกดเริ่มแปลหน้าจอ
4. ยืนยันหน้าต่าง Android ที่ถามว่าจะเริ่มบันทึก/จับภาพหน้าจอหรือไม่
5. สลับไปหน้าเว็บมังฮวา
6. กลับเข้าแอปแล้วกดหยุดแปลเพื่อปิดบริการ

## ขั้นต่อไป
- เพิ่ม ML Kit Translation เพื่อแปลเป็นไทยแบบออฟไลน์หลังดาวน์โหลดโมเดล
- เพิ่มตัวเลือก Google Cloud Translation / AI API แบบเสียค่าใช้จ่าย
- เพิ่มระบบตรวจจับภาษาอัตโนมัติและจัดการคำศัพท์/ชื่อตัวละคร
- ปรับ overlay ให้ลบ/บังข้อความเดิมอย่างเหมาะสมและจัดวางคำแปลตามกรอบคำพูด
